A **Minecraft-inspired engineer portfolio website** built using **pure HTML & CSS**, featuring pixel-art aesthetics, block-style layouts, and a retro gaming vibe.

🌍 **Live Website (GitHub Pages):**

---

## 📜 About

This project is a **personal portfolio website** designed in the style of **Minecraft UI blocks**.

It showcases:
- About Me
- Projects
- Experience
- Skills
- Contact Links

All styling is done **without frameworks** using:
- Custom CSS
- Pixel-art layouts
- Google Fonts (`Press Start 2P`)
- Video background overlay

---

## 🏗️ Features

- 🎮 Minecraft-themed UI
- 📦 Block-style sections (Grass, Dirt, Stone)
- 🎥 Video background support
- 📱 Fully responsive layout
- 🚀 GitHub Pages compatible
- 🧱 No JavaScript required
